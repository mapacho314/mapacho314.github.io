## 🌐 Cómo Publicar en GitHub Pages (Paso a Paso)

Puedes publicar este sitio de forma 100% gratuita en GitHub Pages siguiendo cualquiera de estas dos opciones:

### Opción A: En tu repositorio de perfil (`mapacho314.github.io`)
1. Crea un repositorio público en GitHub llamado exactamente: `mapacho314.github.io`.
2. Sube los archivos `index.html`, `styles.css`, `app.js` y `Profile.pdf` a la rama `main`.
3. ¡Listo! Tu página estará automáticamente activa en: **`https://mapacho314.github.io`**.

### Opción B: En este u otro repositorio (ej. `Coursera` o `cv-landing`)
1. Ve a tu repositorio en GitHub: [https://github.com/mapacho314](https://github.com/mapacho314).
2. Haz clic en **Settings** (Configuración) > pestaña **Pages** (en el menú lateral izquierdo).
3. En **Build and deployment** > **Source**, selecciona `Deploy from a branch`.
4. En **Branch**, selecciona tu rama principal (ej. `main`) y la carpeta `/ (root)`.
5. Haz clic en **Save**. En 1-2 minutos tu landing page estará disponible en:
   `https://mapacho314.github.io/<nombre-del-repo>/`
